Special permission bits use a leading 4th octal digit:
- `4000`: SetUID (`u+s`)
- `2000`: SetGID (`g+s` — on directories, new files inherit parent directory group)
- `1000`: Sticky bit (`+t` — on directories, only file owner or root can delete files)
To set `2770`: `chmod 2770 dropbox`.
To change group: `chgrp billing dropbox`.
