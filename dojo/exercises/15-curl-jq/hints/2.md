To capture only the HTTP status code from a request using `curl`, discard the body with `-o /dev/null` and format the status with `-w "%{http_code}"`:

```bash
# Unauthenticated POST
curl -s -o /dev/null -w "%{http_code}" -X POST "http://127.0.0.1:$(cat API_PORT)/notes"

# Authenticated POST with custom header
curl -s -o /dev/null -w "%{http_code}" -X POST -H "X-Auth: chiya" "http://127.0.0.1:$(cat API_PORT)/notes"
```
