To parse JSON arrays and filter objects with `jq`:

```bash
PORT=$(cat API_PORT)

# Extract all names as raw strings (without JSON quotes)
curl -s "http://127.0.0.1:${PORT}/customers" | jq -r '.[].name' > names.txt

# Filter premium customers and extract their IDs
curl -s "http://127.0.0.1:${PORT}/customers" | jq -r '.[] | select(.plan == "premium") | .id' > premium.txt

# Count items in array
curl -s "http://127.0.0.1:${PORT}/customers" | jq 'length'
```
