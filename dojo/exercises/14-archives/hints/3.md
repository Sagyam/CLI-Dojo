To create an archive using `zstd` compression, changing directory with `-C` so paths are relative to `etc/`, and excluding `*.log` files:

```bash
tar --zstd -cf backup-today.tar.zst -C etc --exclude='*.log' .
```

To calculate the sha256 checksum and update `answers.txt`:
```bash
sha256sum etc/radius/radius.conf
```
