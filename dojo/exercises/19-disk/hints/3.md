To truncate a file down to 0 bytes without deleting its inode or breaking open file descriptors:

```bash
truncate -s 0 disk-arena/app.log
# Or using shell redirection:
# : > disk-arena/app.log
```
Check `answers.txt` to complete the questions about the fullest mount point (`/var/log`) and why deleting open files fails to free space immediately (`c`).
