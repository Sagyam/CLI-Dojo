For `report.sh`, format output with `<count>\t<ip>`:
```bash
#!/usr/bin/env bash
set -euo pipefail
INPUT="${1:-}"
if [[ -f "$INPUT" ]]; then
    awk '{print $1}' "$INPUT" | grep -E '^[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+$' | sort | uniq -c | sort -nr | head -n 5 | awk '{print $1 "\t" $2}'
fi
```
Don't forget to make `report.sh` executable (`chmod +x report.sh`).
