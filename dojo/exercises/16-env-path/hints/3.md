To run the tool and inspect your `$PATH`:

```bash
# Export in your current subshell or start a new shell session
export YETI_ENV=$(cat DEPLOY_ENV.txt)
export YETI_REGION=ap-south-1

# Run the command and save token
yetideploy > token.txt

# Find first directory in PATH
echo "$PATH" | cut -d: -f1
```
