To make `yetideploy` resolvable without specifying `./tools/yetideploy`, make it executable and place it in a directory on your `$PATH`:

```bash
chmod +x tools/yetideploy
mkdir -p ~/bin
ln -sf "$HOME/dojo/16-env-path/tools/yetideploy" "$HOME/bin/yetideploy"
```
Because `~/bin` is in the default `$PATH`, the command will be found immediately.
