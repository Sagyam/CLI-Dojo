### Hints for Tickets 1, 2, & 3

**Ticket 1 (Disk Bloat):**
To truncate an active file to 0 bytes without deleting it or killing its process:
```bash
truncate -s 0 incident/app.log
```

**Ticket 2 (Stubborn Daemon):**
A process that traps `SIGTERM` must be sent uncatchable `SIGKILL` (signal 9):
```bash
pkill -9 -f "^stubbornd"
```
*(Do NOT kill `yeti-authd`!)*

**Ticket 3 (Rogue Config):**
Search for the rogue subnet `198.51.100.` across all files in `incident/configs/`:
```bash
grep -rl "198\.51\.100\." incident/configs/ > t3_rogue_file.txt
```
