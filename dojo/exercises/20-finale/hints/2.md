### Hints for Tickets 4 & 5

**Ticket 4 (Permissions):**
To change permissions of a file to `rw-r-----` (`640`):
```bash
chmod 640 incident/secure/billing.conf
```

**Ticket 5 (Log Forensics):**
To extract the top 3 client IP addresses from `incident/access.log`:
```bash
awk '{print $1}' incident/access.log | sort | uniq -c | sort -nr | head -n 3 | awk '{print $1 "\t" $2}' > t5_top3_ips.txt
```

To count total 5xx HTTP responses (status codes starting with 5 in field 9):
```bash
awk '$9 ~ /^5[0-9]{2}$/ {count++} END {print count}' incident/access.log
```
Record the number into `answers.txt` under `t5_total_5xx:`.
