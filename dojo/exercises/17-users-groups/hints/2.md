To count accounts with real login shells, filter out service shells ending in `nologin`, `false`, or `sync`:

```bash
grep -vE '(nologin|false|sync)$' /etc/passwd | wc -l
```

To find users in the `sudo` group:
```bash
getent group sudo | cut -d: -f4
```
Remember that fields in `/etc/passwd` are:
`username:password:UID:GID:GECOS:home:shell` (login shell is field 7).
