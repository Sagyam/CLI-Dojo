For `solution.sh`, structure the script to take `$1` as the file argument:
```bash
#!/usr/bin/env bash
INPUT="${1:-}"
if [[ -f "$INPUT" ]]; then
    tail -n +2 "$INPUT" | sort -t, -k4,4nr | head -n 5 | awk -F, 'NF>=4 {print $1 "\t" $4}'
fi
```
Don't forget to make it executable with `chmod +x solution.sh`.
